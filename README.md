# Steam 余额折扣计算器

一个用 C 语言编写的命令行工具，用于在 Steam 社区市场出售物品时，快速计算扣除手续费后的实际到手余额，并辅助判断交易盈亏。

## 项目简介

在 Steam 社区市场挂售物品时，买家支付的价格并非卖家最终到账的金额。平台会扣除一定比例的手续费（通常为 15%），实际进入 Steam 钱包的余额会低于标价。本工具通过输入成本、售价和费率，一键算出到手余额与成本到手比，帮助你在上架前评估收益。

## 功能特性

- 输入成本、售价、费率，实时计算到手余额
- 支持默认费率与自定义费率
- 输出“成本 / 到手余额”，直观判断盈亏
- 循环输入，可连续计算多件物品
- 支持输入 `0 0` 或 `0 0 0` 退出

## 计算公式

```text
到手余额 = 售价 × (1 - 费率)
成本到手比 = 成本 / 到手余额
```

若希望到手固定金额，可反推挂售价：

```text
挂售价 = 想到手余额 / (1 - 费率)
```

## 使用说明

程序启动后，会循环显示输入提示：

```text
成本 售价 费率(默认0.13,0 0 0退出):
```

输入格式为：

```text
成本 售价 [费率]
```

| 参数 | 含义 | 是否必填 | 默认值 |
|---|---|---|---|
| 成本 | 获得该物品的实际花费 | 是 | 无 |
| 售价 | 在 Steam 市场挂出的买家支付价格 | 是 | 无 |
| 费率 | 手续费率，输入小数 | 否 | 0.13 |

**示例输入：**

```text
100 150
```

表示成本 100，售价 150，使用默认费率 0.13。

```text
100 150 0.15
```

表示成本 100，售价 150，费率 15%。

**退出方式：**
输入 `0 0` 或 `0 0 0` 即可退出程序。

## 输出说明

示例输出：

```text
费率:15.00% | 到手:127.50 | 折扣:0.7843
```

| 字段 | 含义 |
|---|---|
| 费率 | 当前使用的手续费率 |
| 到手 | 扣除手续费后实际到账的 Steam 余额 |
| 折扣 | 成本 / 到手余额，用于判断盈亏 |

**盈亏判断：**

- `折扣 < 1`：到手余额 > 成本，**盈利**
- `折扣 = 1`：到手余额 = 成本，**刚好回本**
- `折扣 > 1`：到手余额 < 成本，**亏损**

## 使用示例

### 示例 1：默认费率

输入：

```text
100 150
```

计算过程：

```text
到手 = 150 × (1 - 0.13) = 130.50
折扣 = 100 / 130.50 ≈ 0.7663
```

输出：

```text
费率:13.00% | 到手:130.50 | 折扣:0.7663
```

### 示例 2：Steam 常见 15% 费率

输入：

```text
100 150 0.15
```

计算过程：

```text
到手 = 150 × 0.85 = 127.50
折扣 = 100 / 127.50 ≈ 0.7843
```

输出：

```text
费率:15.00% | 到手:127.50 | 折扣:0.7843
```

结果 `0.7843 < 1`，说明盈利。

### 示例 3：亏损情况

输入：

```text
100 100 0.15
```

计算过程：

```text
到手 = 100 × 0.85 = 85.00
折扣 = 100 / 85 ≈ 1.1765
```

输出：

```text
费率:15.00% | 到手:85.00 | 折扣:1.1765
```

结果 `1.1765 > 1`，说明亏损。

## Steam 手续费说明

Steam 社区市场的手续费目前通常为 **15%**，由两部分组成：

- **Steam 交易费**：5%（最低 $0.01）
- **游戏开发商 / 发行商费用**：10%
- **合计**：约 **15%**

因此实际使用时建议手动输入 `0.15`，而不是依赖代码中的默认值 `0.13`。本程序默认的 `0.13` 仅为代码初始值，不代表 Steam 当前标准费率。

此外，Steam 对每笔交易存在最低手续费，低价物品的实际到手金额可能因四舍五入而产生较大比例偏差。请以 Steam 市场页面显示的“你收到”为准。

## 注意事项

- 费率必须输入小数，`0.15` 表示 15%，**不要**输入 `15`
- 输入两个数字时，程序使用默认费率 `0.13`
- 输入三个数字时，第三个数字为费率
- 若费率为 `0` 或负数，程序会自动回退到默认值 `0.13`
- 若到手金额 ≤ 0，程序输出“无效”并跳过本次计算
- “折扣”字段的实际含义是“成本 / 到手余额”，并非传统意义上的商品折扣
- 程序未处理 EOF（如 Ctrl+D / Ctrl+Z），如需退出请使用 `0 0` 或 `0 0 0`

## 反推挂售价

如果你希望卖完后到手一个固定金额，可使用以下公式反推挂售价：

```text
挂售价 = 想到手余额 / (1 - 费率)
```

**示例：** 想到手 100 元，费率按 15%：

```text
挂售价 = 100 / 0.85 ≈ 117.65
```

即挂约 117.65 元，扣除 15% 手续费后，到手约 100 元。
